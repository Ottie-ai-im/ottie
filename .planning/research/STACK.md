# Stack Research — v1.11 User Flow Polish

**Domain:** Cross-platform developer tool (Expo + React Native + Web + Tauri v2) — polish milestone on top of an already-shipped v1.10 product
**Researched:** 2026-04-29
**Confidence:** HIGH for libraries Ottie already uses; MEDIUM for net-new additions (verified npm versions and current docs); LOW marked explicitly per row.

> **Important framing:** Ottie at v1.10 already has a _complete_ primary stack (Expo 54 / RN 0.81 / Unistyles 3.2 / Reanimated / gorhom-bottom-sheet / floating-ui / TanStack Query+Virtual / Zustand / expo-router 6 / expo-haptics / Tauri v2). This research is **strictly additive** — it identifies the smallest set of _new_ libraries and patterns the team should layer on the existing stack to hit the v1.11 polish goals. Any "Recommended" entry that overlaps with `.planning/codebase/STACK.md` is restated only to anchor compatibility for the additions around it.

| **`useTransition` for command-palette + workspace switching**            | Non-blocking transitions during cmdk filter / workspace switch                    | Command Center, Sidebar                                                                    | Keeps the palette interactive while heavy reducers run. Also React 19 native.                                                                                                                                                                                                                                 |
| **TanStack Query + WebSocket-as-invalidation-signal** (TkDodo's pattern) | Use WS messages as `queryClient.invalidateQueries` triggers, not as data carriers | Sessions, Sidebar (recent N), Workspaces                                                   | Ottie already uses TanStack Query + WebSocket. ## Stack Patterns by Variant

**If iOS 26+ device:**

- Render Glass surfaces using `<GlassView>` from `expo-glass-effect`
- Use `PlatformColor("label")` / `PlatformColor("systemBackground")` to make tints respond to Liquid Glass auto-contrast
- Haptics: prefer `Haptics.selectionAsync()` for high-frequency state-change feedback (agent run-start/run-end)

**If iOS 18–25 or Android:**

- Render the same `<GlassSurface>` component, but its implementation forks via Metro extensions (`glass-surface.ios.tsx` for iOS-26-only Liquid Glass, `glass-surface.tsx` fallback using `expo-blur`)
- Haptics on Android: `notificationAsync` is the primary; selectionAsync is silent on most devices — gate or replace with light vibration

**If Web (browser):**

- Skip `expo-glass-effect` entirely (returns a plain View on web). Use a CSS `backdrop-filter: blur()` inside the `glass-surface.web.tsx` variant, gated behind `@supports (backdrop-filter)`
- `react-hotkeys-hook` becomes the primary action surface (no haptics, no long-press)
- cmdk renders as a centered modal palette

**If Tauri Desktop:**

- Same as Web, plus: `tauri::api::globalShortcut` for system-wide chord (`Cmd+Shift+O` to summon Ottie even when window is hidden) — wire via the existing Tauri bridge
- File-dialog flows go through `getIsElectron()` gate, not `isWeb`

**If Compact form factor (`useIsCompactFormFactor() === true`):**

- Command center renders as a `@gorhom/bottom-sheet` modal, not a centered cmdk palette (Metro split)
- Hover-only controls always visible (`isHovered || isNative || isCompact` per CLAUDE.md)
- Sidebar is overlay, not pinned

**If new agent-creation flow (AGT-04 — instant feedback):**

- Wrap submit handler with `useOptimistic` + `useTransition`
- Optimistic message appears with `pending` discriminator on the timeline reducer
- Reconcile when first `agent_stream` event arrives (existing Stream model handles dedupe by sequence)
